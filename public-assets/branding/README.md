# Nexoraa branding assets

The original user-supplied logo artwork is preserved unchanged. Transparent PNG variants are technical derivatives that remove only the surrounding background matte so the same logo can sit cleanly on the app's dark surfaces. The mark, NEXORAA wordmark, and slogan retain their supplied artwork and colors.

- `nexoraa-logo-original.png` — original full logo artwork; do not overwrite.
- `nexoraa-logo-transparent.png` — full logo with transparent exterior background; used by the frontend.
- `nexoraa-symbol-crop.png` — original symbol crop with its original matte, preserved.
- `nexoraa-symbol-transparent.png` — transparent-background symbol for compact skill-passport use.

The frontend keeps matching deployment copies under `frontend/public/branding/`. On light surfaces, the full wordmark is white; use the full transparent logo on dark surfaces to retain contrast.
