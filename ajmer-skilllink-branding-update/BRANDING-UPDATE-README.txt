Ajmer SkillLink — branding/auth-screen update

HOW TO APPLY (Windows):
1. Extract this ZIP directly into the existing ajmer-skilllink-complete project root (the folder containing frontend, backend, and database).
2. Allow overwrite for frontend/src/App.jsx and frontend/src/styles.css. The other files add transparent logo derivatives and preserve the original assets.
3. Do not overwrite or remove .env. This update contains no .env, database, migrations, or seed data. It does not reset MySQL.
4. With Vite running, the browser should hot-reload. The UI uses the exact supplied Nexoraa artwork with only the background matte removed. The small duplicate logo on the white login card is omitted for contrast; the full logo and slogan remain on the dark login panel and loading screen.

The full and data-only ZIP archives were also refreshed separately.
